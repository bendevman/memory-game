# memory-game

A classic memory training card game.

### Local Setup Instructions
1. Clone this repository locally:
   ```bash
   git clone https://github.com/bendevman/memory-game.git
   ```
2. Navigate into the project folder:
   ```bash
   cd memory-game
   ```
3. Checkout to the development branch:
   ```bash
   git checkout memory-game
   ```
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start dev server:
   ```bash
   npm run dev
   ```
